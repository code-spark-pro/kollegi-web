# Коллеги

Адаптивный веб-прототип нетворкинг-платформы для проектного сотрудничества.

## Запуск

Для запуска в Яндекс Браузере откройте `start_yandex.cmd`.

Для запуска в браузере по умолчанию откройте `start_site.cmd` или выполните:

```powershell
python -m http.server 8080
```

Откройте `http://127.0.0.1:8080/index.html`.
